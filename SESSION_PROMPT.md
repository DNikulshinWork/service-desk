# Session Prompt

Продолжай реализацию проекта по [SERVICE_DESK_PLAN.md](SERVICE_DESK_PLAN.md) и [SPRINTS_CHECKLIST.md](SPRINTS_CHECKLIST.md).

Работай строго по шагам:
1. Определи следующий не реализованный пункт из плана.
2. Проверь текущее состояние кода и тестов.
3. Найди корень проблемы/пробела, а не угадывай.
4. Сделай минимальную реализацию.
5. Добавь или обнови интеграционные тесты (`app.inject()`), если меняется поведение API.
6. Запусти `pnpm --filter @service-desk/api test`.
7. Обнови [SPRINTS_CHECKLIST.md](SPRINTS_CHECKLIST.md).
8. Сделай понятный коммит и, если нужно, отправь изменения в GitHub.

Не возвращайся к уже проверенным сценариям без причины.
Если после изменений тесты падают — сначала проверь причину, затем исправляй.
